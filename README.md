# GitHub и мышление разработчика

## Что такое GitHub

GitHub — это платформа для хранения кода, совместной работы и управления проектами.  
Она помогает разработчикам:

- хранить проекты в облаке
- отслеживать изменения в коде
- работать в команде
- публиковать свои проекты
- создавать портфолио

GitHub тесно связан с системой контроля версий Git.

---

# Почему GitHub важен для разработчика

GitHub — это не просто сайт с кодом.  
Это часть профессионального мышления разработчика.

Разработчик думает:

- как сохранять изменения безопасно
- как не ломать проект
- как работать в команде
- как делать код понятным
- как улучшать проект постепенно

GitHub помогает выработать именно такой подход.

# Основные команды Git и GitHub для начинающих

## Проверка версии Git

```
git --version
```
## Настройка имени пользователя
```
git config --global user.name "Ваше Имя"
```
## Настройка email
```
git config --global user.email "example@mail.com"
```
## Создание проекта. Инициализация Git в папке
```
git init
```

Создает новый Git-репозиторий.

## Проверка состояния проекта

```bash
git status
```

Показывает изменения в проекте.

---

## Добавление файлов

```bash
git add .
```

Добавляет все файлы в коммит.

---

## Создание коммита

```bash
git commit -m "Описание изменений"
```

Сохраняет изменения.

---

## Отправка проекта на GitHub

```bash
git push
```

Загружает изменения на GitHub.

---

## Скачать изменения

```bash
git pull
```

Получает обновления из GitHub.
